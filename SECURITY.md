# Security

The full security model, hardening checklist and disclosure process live in
[docs/SECURITY.md](docs/SECURITY.md).

**Reporting a vulnerability.** Please do not open a public issue. Use GitHub's
private vulnerability reporting for this repository
(<https://github.com/shadow-kernel/agit/security/advisories/new>). You should hear
back within 72 hours.

**Supported versions.** agit is pre-1.0; only the latest release on `main`
receives fixes.
